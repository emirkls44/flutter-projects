# Flutter Projects

Small Flutter apps I built while learning Dart and Flutter (2025). Mostly UI exercises; they are
kept here together instead of as separate repositories.

| App | What it is |
|---|---|
| [instagram-clone-ui](instagram-clone-ui) | Instagram-style profile and feed screens with a detail page |
| [todo-app](todo-app) | Task list home screen with task model, custom colors and widgets |
| [book-app](book-app) | Starting point of a book app (single screen) |

Run any of them with:

```sh
cd <app>
flutter pub get
flutter run
```

My main focus is embedded firmware; see my [profile](https://github.com/emirkls44) for those projects.
